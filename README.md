# 文本离线传输工具

一个**完全离线**的文本传输工具：把文字变成二维码，然后再使用另外一台设备的摄像头扫描二维码还原文本内容，从而达到文本内容跨设备传输的目的。所有处理都在本机完成，不联网、不上传，断网、内网、飞行模式下都能正常使用，分为 HTML 网页版和微信小程序版。

仓库里包含两个互相兼容的客户端：

| 目录 | 端 | 说明 |
| --- | --- | --- |
| [`html-web/`](html-web/) | PC / 浏览器 | 单文件网页版，双击即用，无需安装、无需联网 |
| [`wechat-miniprogram/`](wechat-miniprogram/) | 手机 / 微信 | 微信小程序，三个标签：发送 / 接收 / 历史记录 |

两端生成的二维码格式完全兼容，任意组合都能互传。

## 下载

到 [Releases](../../releases) 页面可以下载打包好的压缩包：

- `offline-text-transfer-html-web-*.zip` —— 网页版（解压后双击 HTML 即可使用）
- `offline-text-transfer-wechat-miniprogram-*.zip` —— 小程序源码（用微信开发者工具导入即可运行）

## 一、网页版（html-web）

单文件 HTML，把二维码生成与识别引擎全部内嵌在文件里：

- **发送模式**：输入文字 → 生成二维码 → 可直接拿屏幕给对方扫，也可下载图片
- **接收模式**：开启摄像头对准二维码识别，或上传二维码图片（截图 / 文件）识别
- 识别引擎为 ZXing WebAssembly，**已内嵌为 base64，无需联网**

用法：直接用浏览器打开 `html-web/offline-qr-transfer.html`。

## 二、微信小程序（wechat-miniprogram）

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开开发者工具 → **导入项目**
3. 目录选择 `wechat-miniprogram/` 这一层（包含 `app.json`）
4. AppID 选「测试号」或填自己的 AppID，即可预览

三个标签：

- **发送** —— 输入文字生成二维码，可切换纠错等级 L / M / Q / H，可保存到相册
- **接收** —— 微信原生扫码（摄像头 / 相册选图），识别结果可复制或接力再生成
- **历史记录** —— 发送与识别的文字自动存在本机（最多 200 条），可复制、删除

右下角悬浮的「关于」按钮内含完整的图文使用说明。

## 三、两端如何联动

- **电脑 → 手机**：网页「发送模式」生成二维码，手机小程序切到「接收」标签，对准屏幕扫描
- **手机 → 电脑**：小程序「发送」页生成二维码并保存到相册，网页切到「接收模式」，
  上传该图片识别（或直接拿手机屏幕对着电脑摄像头扫）

只有手机或只有电脑时，各自也能自己传给自己，不依赖另一端。

## 四、实现说明

- **二维码生成**：小程序端为自研纯 JS 编码器（`wechat-miniprogram/utils/qr-encoder.js`），
  零依赖，支持 UTF-8（中文 / emoji）、版本 1–40、纠错等级 L/M/Q/H、自动掩码择优
- **二维码识别**：小程序直接用微信原生 `wx.scanCode`；网页端用内嵌的 ZXing WebAssembly
- **隐私**：两端内容均在本机处理，不上传；历史记录存在本机存储 / 浏览器本地存储中，
  换设备或清缓存会丢失，重要内容请及时另行保存
