# 离线二维码小程序（发送 / 接收 / 历史记录）

一个纯本地的二维码工具：生成二维码、扫码识别、查看历史记录。内容不会上传到任何服务器。

## 一、如何运行

1. 下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开开发者工具 → **导入项目**
3. 目录选择本文件夹（包含 `app.json` 的那一层）
4. AppID 选择 **「测试号」**（或填你自己的 AppID）
5. 点确定即可预览；想真机体验就点右上角「预览」用微信扫码

> 文件夹里已带 `project.config.json`，导入后一般不需要再改设置。

## 二、三个功能模块（底部导航）

### 1. 发送 —— 把文字变成二维码
- 输入文字（中文、emoji、链接都支持，最多 2000 字）
- 点「生成二维码」：二维码会**按屏幕宽度自动最大化**显示，无需手动调尺寸
- 可切换纠错等级 L / M / Q / H（默认 M）
- 「保存到相册」把二维码存成图片，方便发给别人

### 2. 接收 —— 扫码读出二维码里的文字
- 「打开摄像头扫码」：调用微信原生扫码，识别最快、最省电
- 「从相册选二维码识别」：不用摄像头，从截图/相册里识别
- 识别结果自动显示，可一键复制、或直接跳到「发送」页重新生成二维码
- 识别到的内容会自动记入历史记录

### 3. 历史记录 —— 发送 / 接收的文字都在这里
- 每条记录带 **发送/接收 标签**、**时间标签**（今天/昨天/日期）、字数
- 每条可 **复制内容** 或 **删除**
- 支持 **下拉刷新** 和右上角 **清空全部**
- 内容较长的记录点一下可查看完整内容
- 最多保留 200 条，保存在本机

### 4. 关于 —— 右下角悬浮的使用说明
- 三个页面右下角都有「关于」悬浮按钮，点开是完整的图文使用说明
- 内容包含：这是什么、三个标签怎么用、和电脑端网页版怎么联动、小贴士、开源地址与下载
- 「开源地址」「下载最新版」两行点一下即复制完整链接（小程序里不能直接跳外链，复制后粘贴到浏览器打开）
- 点遮罩或「知道了」关闭；切到别的页面会自动收起

## 四、实现说明

- **二维码生成**：自己实现的编码器（`utils/qr-encoder.js`），零依赖、可离线，支持
  UTF-8（中文/emoji）、版本 1–40、纠错等级 L/M/Q/H、自动掩码择优。
  生成的二维码已用 ZXing 逐条验证，可被微信/手机相机正常扫出。
- **扫码识别**：直接使用微信原生 `wx.scanCode`，识别率与系统相机一致，
  同时支持摄像头扫码和相册选图，不需要自研解码、包体也更小。
- **隐私**：全部处理都在手机本地完成，不联网、不上传；历史记录存在本机存储里，
  卸载小程序会一并删除，重要内容请及时另行保存。

## 五、常见问题

**扫码提示需要权限？**
首次使用摄像头/相册时微信会申请权限；若误点拒绝，可在右上角「···」→ 设置里重新开启。

**历史记录会丢吗？**
记录存在本机，换手机或删除小程序会丢失。重要内容建议用「复制内容」另存到备忘录。

**生成的二维码扫不出来？**
把手机屏幕亮度调高、让对方离远一点（10～30 厘米）；内容很长时二维码会很密，可考虑拆成多段。
